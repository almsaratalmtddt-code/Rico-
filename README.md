# مسارات ERP
نواة ERP ويب لشركة المسارات المتعددة للاتصالات، مبنية لتعمل على Cloudflare Workers + D1.

## النطاق الأولي
- لوحة تحكم
- العملاء
- الأصناف والمخزون
- المبيعات والمشتريات
- المصروفات
- القيود المحاسبية
- التقارير

## التشغيل
1. أنشئ قاعدة D1 باسم `masarat-erp-db`.
2. ضع `database_id` في `wrangler.toml`.
3. نفّذ `npx wrangler d1 execute masarat-erp-db --remote --file=./db/schema.sql`.
4. نفّذ `npm install` ثم `npm run deploy`.

سيتم تطوير الوحدات المحاسبية والضريبية والصلاحيات والفواتير التفصيلية في الإصدارات التالية.
